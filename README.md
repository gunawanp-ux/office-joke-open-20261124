# office-joke-open

A one-line office joke entered in make.fun's "Make the AI Judge Laugh: the Office Joke Open". The program writes a single joke about office life — a reply-all storm that ends in an unlikely promotion — to `/output/entry.txt`, where an AI judge compares it head-to-head against the other entries in blind rounds.

## Run it

```sh
python3 main.py
```
